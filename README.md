# MentorEdu API

API REST principal de la plataforma MentorEdu. Gestiona autenticación, perfiles, biblioteca, foro, pedagogía y comunidad.

## Stack

- Java 21 + Spring Boot 4.0.6
- PostgreSQL 16 + Flyway
- JWT + Spring Security
- Docker · Render.com
